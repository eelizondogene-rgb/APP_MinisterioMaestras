# Requerimiento: digitalización de calendarios actuales

La imagen `referencia-calendario-actual.png` se conserva únicamente como evidencia del proceso manual observado durante el levantamiento de requerimientos.

El sistema no almacena el calendario como una imagen. La información se transforma en datos estructurados:

- Grupo de clase.
- Rango de edad.
- Año y mes.
- Una o varias maestras por grupo/mes.
- Tema, material y observaciones opcionales.
- Fechas dominicales de protocolo.
- Responsable de merienda.
- Responsable de protocolo.
- Tareas y bitácora.

Esto permite editar el calendario, filtrar lo que ve cada maestra, generar recordatorios, pasar asistencia según el grupo asignado y volver a imprimir el calendario cuando sea necesario.
