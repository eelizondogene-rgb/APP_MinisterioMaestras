Instalar Niños para Cristo

En iPhone o iPad, instala la aplicación desde Safari:

  1. Toca Compartir ⇧.
  2. Selecciona Agregar a pantalla de inicio.
  3. Abre Niños para Cristo desde el nuevo ícono.
  4. Dentro de la app toca Activar notificaciones.
